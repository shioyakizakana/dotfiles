# Secret Management Review

リポジトリのAGENTS.mdに従い、コードと設定から秘密情報の流れを評価する。

1. 対象差分と呼び出し元を確認し、レビューの範囲を決める。
2. [確認観点](references/checklist.md)の該当箇所を読み、取得・保持・受け渡し・破棄を追う。
3. 実データを確認する代わりに、既存のダミー値とモックが検証する範囲を調べる。
4. 確認した問題、潜在的なリスク、未確認事項を分けて報告する。

指摘には重要度、ファイルと行番号、発生条件、影響、修正案、必要な回帰テストを示す。
レビューの依頼だけで実装や認証操作へ進まない。テスト実行が依頼範囲に含まれる場合はdotfiles-test-runnerの対応表を使い、全テストの手順をここへ重複させない。
