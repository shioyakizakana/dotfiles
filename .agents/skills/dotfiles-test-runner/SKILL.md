# Dotfiles Test Runner

リポジトリのAGENTS.mdに従い、依頼範囲に必要な検証を選ぶ。

1. Gitルート、変更対象、関連テストを確認する。テストの依頼と修正の依頼を区別する。
2. [対応表とコマンド](references/commands.md)から検証を選び、実行前に副作用と依存を確認する。
3. 関連テストを実行し、影響範囲や失敗に応じて全体へ広げる。
4. 実行コマンド、成功・失敗・skip・未実施、その理由を報告する。

依存不足を自動インストールで解消せず、承認の有無を確認する。既知の失敗も結果から除外しない。
テンプレートの評価方法はchezmoi-template-validationを参照する。同じ変更について実行済みの検証結果があれば再利用し、再実行の要否を判断する。
