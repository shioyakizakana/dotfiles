# 言語別の実装規約

## Bash

- 原則として`#!/usr/bin/env bash`と`set -euo pipefail`を使う。
- 変数を適切に引用し、外部コマンドの存在を確認する。
- エラーと終了状態を扱い、安全に作った一時ファイルを正常・異常終了の両方で削除する。
- 既存の関数名・定数名・ログ規則を維持する。
- Bash専用構文はシバンを合わせ、GNU固有オプションは対象環境を確認する。

## Python

- 既存の対応Python版を維持し、パス操作には原則pathlibを使う。
- 標準ライブラリで足りる場合は外部依存を増やさず、既存のunittestを優先する。
- 秘密情報を例外メッセージへ含めない。

## 導入・更新

- 副作用を持つMakeターゲットは実行前に内容を確認する。
- インストール・更新・通信の承認を、スキルの利用承認と混同しない。
- 不足がない場合・辞退・EOF・部分失敗・再実行の振る舞いを確認する。
