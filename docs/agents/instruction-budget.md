# 規約の字数を確認する

AGENTS.mdは全体規則と局所規則に分け、作業手順はスキルで必要なときに読む。元の指示と移動先は[対応表](rule-mapping.md)で確認する。

## 確認コマンド

リポジトリルートで実行する。Python標準ライブラリだけを使い、設定適用・認証・通信は行わない。

```shell
# 配布元の短縮後規約で、適用後を見積もる。make lintとCIも同じ対象。
python3 -B tests/check_instruction_budget.py --global-source

# 現在の展開済みグローバル規約を含めて確認する。
python3 -B tests/check_instruction_budget.py
```

グローバル規約の配置が異なる環境は`--global-file PATH`で指定する。`--root PATH`で対象リポジトリを変更でき、`--json`で結果を取得できる。

## 数え方と上限

- UTF-8をデコードしたUnicode文字数を数え、空白・改行・記号・SKILL.mdのfrontmatterも含める。
- 自作のAGENTS.md・AGENTS.override.md・SKILL.mdを1本1000字以内にする。
- 常時合計はGLOBALとルートから対象フォルダまでのAGENTSを合わせ、8000字以内にする。
- 兄弟フォルダの局所規則や、作業時に選ぶSKILL.md本文は常時合計に加えない。
- リンクは参照先を表示して1回だけ計上し、別の実ファイルは同じ内容でも別に数える。
- overrideを優先し、空なら通常のAGENTS.mdへ戻る。
- 超過・参照切れ・読取失敗・規約未配置では終了コード1を返す。

理由・実例・履歴の資料と、外部・システム配布スキルはこのリポジトリの規則ファイル上限の対象外とする。スキル内の実装手順は適用時に読み、今回移した手順ファイルも1000字以内に分割した。

`--global-source`では共通規約の配布元を将来のGLOBALとして数える。その配布元フォルダを作業対象にすると、将来は展開先と配布元の2実体を読むため、両方を常時合計へ含める。実際に展開先が短縮されたことを示す結果ではない。

## 変更前との比較

再編前の字数とハッシュは[instruction-budget-baseline.json](instruction-budget-baseline.json)に保存した。スクリプトは各ファイルと、ルート・最大常時合計の変更前後を表示する。追加ファイルの変更前は0字とする。

共通規約のソースを短縮しても、適用するまでは現在の展開済み規約が残る。今回の作業で展開先は変更しないため、適用前のローカル実行はGLOBALの1000字超過を報告する。適用は利用者が内容と共通スキルの配置を確認して別途行う。

規約・スキルを変更するときは配布元モードを実行し、変更に応じて[テスト](../testing/checks.md)と文章確認も行う。
